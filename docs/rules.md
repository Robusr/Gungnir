# Gungnir 领域规则参考（场景 5A）

本文件是规则引擎（L0）的规格说明，来源于《商战模拟指导手册》和参考决策工具
`决策工具.xls`，用于 M1 阶段的**对拍**验收。所有「待确认」项将在 M1 通过
与决策工具逐项对拍来锁定。

> 代码标识符、注释用英文；本文档与 UI 文案用中文。

## 1. 场景

- 难度 5A（共 9 级）；2 产品（A、B）× 3 市场；10 家同质公司；1 期 = 1 季度。
- 初始现金 2,500,000 元；最低现金 2,000,000 元；信用总额 8,000,000 元。

## 2. 生产资源（单件）

| 资源 | A | B |
|------|------|------|
| 机器（时） | 100 | 200 |
| 人力（时） | 150 | 250 |
| 原材料（单位） | 300 | 1500 |

- 一期正常班 520 小时，加班 260 小时；工人每天最多 12 小时，机器每天最多 20 小时（可两班）。
- 机器价 40,000 元/台，每期折旧 5%；机器维修费 200 元/台/期。
- 买机器时序：本期末付款 → 下期运输安装 → 再下一期使用（延迟 2 期）。
- 机器与人按 `机器时:人时` 比例搭配，多余则闲置/不上班只领基本工资。

> 待确认：手册 FAQ 2.2 写「A 产品 100:180；B 200:180」，与生产表（100:150 / 200:250）
> 冲突。按生产表 + 任务规格（3.2）实现，FAQ 2.2 视为笔误。

## 3. 库存与分销

- 本期产量 **75%** + 工厂库存 = 可运出量；市场间不转运；只要运货即付固定运费 + 变动运费。
- 成品库存费：A=20 元/件，B=80 元/件；原材料库存费 0.05 元/元/期。
- 库存费只对「跨期结转」的库存计（当期生产/购入且当期消耗/销售的不计，FAQ 3.10）。
- 供不应求时，多余需求按比例转下期订货（订货多是定价不准的坏信号）。
- 本期订购原材料至多 50% 可用于本期生产。

## 4. 研发

- 生产某产品需先投等级 1 研发费；每期最多升 1 级。
- 累计研发费：A `100k/200k/300k/400k/500k`；B `200k/350k/480k/600k/700k`。
- 研发费在本期与下一期平均分摊（`(上期研发 + 本期研发) / 2` 计入本期成本）。
- 研发等级对后续各期长期生效；工资系数只对本期生效（调整产品等级）。
- 产品等级由「研发累计等级 + 工资系数」共同决定（FAQ 2.7：L1 实际等级 ∈ [1, 1.9]）。

## 5. 人力

- 招聘 ≤ 期初人数 50%；新工人培训费 500 元/人，培训期工资为正式工 25%（4 人折合 1 人）。
- 每期 3% 正常退休；解聘（含退休）≤ 期初人数 10%；安置费 1,000 元/人。
- 工资系数 ≥ 1.0。
- 基本工资 = 本期在岗人数 × 520 × 小时基本工资 × 工资系数（新工人 4 人折 1 人）。
  - 对拍确认：`145 × 520 × 3 × 1.02 = 230,724`（参考工具 财务!R8），故 `小时基本工资 = 3`。
- 特殊班工资 = 二班正班超出部分 + 一班加班 + 二班加班。

> 待确认：小时工资表原始值 `(3, 4.5, 4, 6)` 到
> {一班/二班} × {A/B} 及加班费率的精确映射（见 `gungnir/config.py` LaborParams）。

## 6. 资金

- 银行贷款年利率 8%（当期期末还本息）；债券 12%、分 20 期还本；国债 6%；紧急救援贷款 40%。
- 税率 30%（本期净收益）；分红条件：期末现金 > 2,000,000 且 ≤ 本期税后利润。
- 债券上限 = 净资产 × 50%；债券不能提前还。
- 原材料批量优惠：订购量 `[0,1M) 1.00 / [1M,1.5M) 0.96 / [1.5M,2M) 0.92 / ≥2M 0.88`。

> 待确认：债券本金偿还公式。手册写「累计发债券 × 比例」，参考工具当期还本金 20,500、
> 上期 18,000、上期发债 50,000（差 2,500 = 50,000/20），需在 M1 用 20 期等额摊还模型对拍。

## 7. 现金收支次序（L0 现金流仿真的骨架）

参考工具 `财务` 表的实际顺序（比手册第 3.7 节更细）：

```
期初现金 → 银行贷款 → 发债券
  → 还债券本金 → 还债券利息
  → 新工人培训费 → 解雇安置费 → 工人基本工资 → 机器维修费
  → 【紧急救援贷款判定点：若此时现金 < 0，按 40% 借入】
  → 研发费（现金支出；分摊另计入成本）
  → 购原材料（现金）→ 购原材料优惠（收入）→ 购材料运费（现金）
  → 特殊班工资 → 管理费 → 使用材料费（仅成本）→ 成品运输费 → 广告费 → 促销费
  → 销售收入 → 废品损失 → 折旧费（仅成本）→ 产品库存变化（仅成本）
  → 原材料存储费 → 成品存储费
  → 上期国债本金返回 → 上期国债利息
  → 付银行贷款 → 付银行利息
  → 上期紧急救援贷款本/息
  → 本期纳税 → 买机器 → 分红 → 买国债
```

**致命规则**：资金不足时系统按此次序支出并「随意修改决策（不遵循优化原则）」——引擎必须保证
任何提案都不会走到这一步；现金不足（到机器维修费之前）会触发紧急救援贷款（40%）。

## 8. 成本 / 收入口径

- 本期收入总额 = 原材料优惠 + 销售收入（+ 国债利息等）。
- 销售收入 = Σ市场【上期订货 × min(上期价, 本期价) + (本期销量 − 上期订货) × 本期价】。
- 废品数 = 供货量 × 正品率（四舍五入）；废品损失 = Σ 废品数 × 该产品该市场价格 × 40%。
- 折旧费 = 机器价 × 机器数 × 5%。
- 管理费 = Σ 实际使用的 (产品, 班次) 固定费用（A 一班 4000 / A 二班 5000 / B 一班 6000 / B 二班 7000）。
  - 对拍确认：A 一班 + B 一班 + B 二班 = 4000+6000+7000 = 17,000（参考工具 财务!R17）。
- 成品运输费 = Σ市场 [固定运费(若运量>0) + 变动运费 × 运量]。
  - 对拍确认：A `680+100×34 + 1820+314×91 + 4000+400×200`，B 同法，合计 490,324（财务!R19）。
- 使用材料费 = Σ 产品产量 × 单件原材料单位。
  - 对拍确认：A 400×300 + B 190.56×1500 = 405,840（财务!R18）。

> 待确认：正品率（废品率）参数值未在参数表显式出现，需对拍 财务!R23 废品损失 42,400 反推。
> 待确认：「交税信用」机制（公司状况 R13 = -2,475）对本期纳税的调整。

## 9. 评分体系（七项指标 + 权重）

| 指标 | 权重 |
|------|------|
| 本期利润 | 0.20 |
| 净资产 | 0.20 |
| 市场份额 | 0.15 |
| 资本利润率 | 0.15 |
| 累计分红 | 0.10 |
| 累计缴税 | 0.10 |
| 人均利润率 | 0.10 |

- 标准分 Z-score：`(企业值 − 均值) / 标准差`，再加权求和。
- 市场份额 = 各产品 × 各市场销量占有率分别算标准分后求平均。
- 资本利润率分母 = 净资产 + 未偿还债券；人均利润率人数 = 本期解聘 + 新雇 + 在岗。
- 上期综合分加权计入本期（滞后影响）；预留现金 < 期初现金或本期成本 → 标准分下调。

> 待确认：上期综合分滞后权重；预留现金下调的具体规则；累计缴税/分红的 7% 净现值折算（FAQ 3.4）。

## 10. 取整约定

- 决策变量输入为整数；8.4 人 → 9 人；120.6 件 → 至多 120 件。
- 退休 7.6 → 7（FAQ 4.1 向下取整）；解聘（需手动）8.4 → 9（FAQ 5.4 向上取整）。

## 11. 输入 / 输出实体（对应数据模型）

- `GameState`（期初状态）：现金、机器数、各产品库存、原材料、等级、工资系数、工人数、
  贷款/债券/国债、累计研发、累计缴税/分红、上期利润、净资产等。
- `Decision`（一期决策）：定价(2×3)、广告(2)、促销(3)、供货量(2×3)、产量(2×4 班次)、
  研发投入(2)、招聘/解聘、买机器、买原材料、贷款/发债/买国债/分红、工资系数。
- `PeriodResult`（期末结果）、`CashFlowLine`（现金流明细）、`ScoreBreakdown`（七项评分）。
